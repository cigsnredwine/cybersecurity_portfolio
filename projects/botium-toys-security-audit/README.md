# Botium Toys — Internal Security Audit Lab

## Overview

For this document-based audit of Botium Toys, a fictional retailer, I reviewed the supplied risk assessment and completed a controls and compliance checklist. Of 14 security controls, I marked 5 present and 9 absent or inadequate. My recommendations addressed excessive access, missing encryption, recovery planning, and monitoring gaps.

## Tools and Topics

- **Security controls:** Assessing access management, data protection, and physical safeguards.
- **Risk assessment:** Reviewing the scenario's assets and documented security gaps.
- **Compliance:** Reviewing checklist items covering PCI DSS, GDPR, and SOC Type 1/Type 2 training categories.
- **Recommendations:** Documenting improvements to passwords, backups, intrusion detection, and legacy system maintenance.
