## Projects

### [Security Risks of Third-Party APIs & Developer Behavior](./projects/secure-cyber-networks-research/)
Research project completed for a Secure Cyber Networks course analyzing cybersecurity risks introduced by third-party APIs, software supply chains, credential leakage, and AI-assisted development.

The project examined the 2026 Vercel OAuth breach, the Axios npm supply chain compromise, exposed secrets in GitHub repositories, and security risks associated with AI-generated code. It also explored mitigation strategies including least privilege, zero trust architecture, dependency auditing, credential scanning, and secure code review.

**Topics:** OAuth Security, Software Supply Chain Security, Secret Management, Zero Trust, AI Security

### [Password Cracking with John the Ripper](./projects/john-the-ripper-password-cracking/)

### [Digital Forensics Investigation](./projects/digital-forensics-investigation/)
Completed a digital forensics investigation in a Forensic Computing course using Windows, FTK Imager, and Autopsy.

The investigation involved forensic data acquisition, creating and configuring an Autopsy case, analyzing a provided `SuspectData.dd` disk image, performing keyword searches, tagging relevant files and images, extracting data, and generating an Autopsy forensic report.

**Tools:** FTK Imager, Autopsy  
**Topics:** Digital Evidence Acquisition, Disk Image Analysis, Keyword Search, Evidence Tagging, Forensic Reporting
